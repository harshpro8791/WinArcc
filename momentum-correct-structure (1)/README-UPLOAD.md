# Momentum Android APK project

The project folders are already arranged in their intended locations. Do not move individual files out of their folders.

Important paths:
- `index.html` and `package.json` are in the project root.
- React source code is in `src/`.
- `src/main.tsx` is the entry point referenced by `index.html`.
- Android APK workflow is `.github/workflows/apk.yml`.
- App images are in `resources/`.

To build on GitHub, upload the CONTENTS of this extracted project folder while preserving folder paths. The GitHub web uploader can be awkward for nested folders; if folders do not preserve correctly, use GitHub Desktop to commit and push the whole extracted project.
